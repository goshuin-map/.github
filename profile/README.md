# ⛩ みんなの御朱印マップ

全国の**神社**で「御朱印がもらえるか」「直書きか書き置きか」を、地図で調べられるWebサイトです。
情報は利用者のみなさんに投稿していただき、運営者が確認してから掲載します。

🌐 **サイト**：https://goshuin-map.github.io/ （準備中・2026年11月公開予定）

## できること

- 🗺 地図のピンの色と形で、御朱印の有無がひと目で分かる
  - 🟢 直書きあり ／ 🟡 書き置きのみ ／ 🔴 御朱印なし ／ ⚪ 情報なし
  - ☆ 限定御朱印・季節の御朱印あり
- 📍 現在地や都道府県から、近くの神社を探せる
- 🔍 神社名での検索、状態ごとの絞り込み
- ✓ 参拝した神社を「行った」として記録（ブラウザにだけ保存。ログイン不要）
- ✍ Googleフォームから情報を投稿
- 🇯🇵 / 🇬🇧 日本語・英語の切り替え

スマートフォンで、神社を巡りながら使うことを想定しています。

## しくみ

サーバーを持たず、無料のサービスだけで運用しています。

| 役割 | 使っているもの |
|---|---|
| サイトの公開 | GitHub Pages（HTML・CSS・JavaScriptのみ） |
| 地図 | Leaflet、OpenStreetMap |
| 神社の位置データ | OpenStreetMap（Overpass APIから月1回取得） |
| 投稿の受付と承認 | Googleフォーム、Googleスプレッドシート、Google Apps Script |
| 自動処理 | GitHub Actions（写真の縮小・位置情報の削除・データ更新） |
